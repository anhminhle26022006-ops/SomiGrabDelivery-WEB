# Somi Admin Access

The public website does not show Admin in its navigation or role selector.

Run the project with `npm.cmd run dev`, then open either:

- http://localhost:5173/internal/admin
- http://localhost:5173/admin

These are internal frontend routes for the demo Admin Dashboard. In the real PHP/MySQL backend, protect the route with authentication and ADMIN authorization.

Public site remains:
- http://localhost:5173/
