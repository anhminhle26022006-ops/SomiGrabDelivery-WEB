# Somi Grab Delivery — Mobile Version

This version is optimized for phone screens while keeping the desktop layout.

## Mobile improvements
- Mobile-first hero layout
- Full-width touch-friendly CTA buttons
- Mobile hamburger menu
- Fixed bottom navigation for Customer / Shipper / Admin
- Responsive dashboard cards
- Responsive order forms and delivery offers
- Admin table remains horizontally scrollable instead of breaking the layout
- Prevents horizontal page overflow

## Run
```bash
npm.cmd install
npm.cmd run dev
```
Then open the Vite URL shown in the terminal, normally `http://localhost:5173/`.
